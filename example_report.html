Executive Summary

Executive summary

Verdict: Malicious (Weedhack RAT loader, high confidence)
- The JAR ExploitPreventer-0.1.10.jar is a trojanized Minecraft/Fabric mod that embeds the Weedhack RAT loader. Multiple, independent detections confirm this (exact class hash matches, Weedhack string/signature hits, ratter_scanner=malicious).
- It masquerades as a mod (“ExploitPreventer”) while staging a remote payload and stealing Minecraft session credentials.

High-level goal
- Stealthy delivery of a second-stage module (Weedhack) combined with credential theft (Minecraft username/UUID/accessToken) and resilient command-and-control (C2) via on-chain configuration.

Observed execution flow
1) Initialization as a Fabric mod (com/example/ExampleMod.onInitialize): logs M0–M4 states; collects Minecraft session data: username, uuid, accessToken, minecraftInfo, userId.
2) C2 discovery via Ethereum JSON-RPC:
   - Calls eth_call against contract 0x1280a841Fbc1F883365d3C83122260E0b2995B74 using many public RPC endpoints (e.g., https://api.zan.top/eth-mainnet).
   - Receives a signed configuration: “https://whreceiverrrrrrrrr.ru|<RSA signature>”; verifies with embedded RSA public key (SHA256withRSA).
3) Stage-2 retrieval and load:
   - Intended download: https://whreceiverrrrrrrrr.ru/files/jar/module (failed in sandbox with 403/host resolve error).
   - Loader uses HttpClient/HttpURLConnection to fetch, JarInputStream + custom ClassLoader/defineClass to load in-memory; then invokes dev.majanito.Main.initializeWeedhack.
4) Exfiltration path:
   - Prepares JSON with credential material and targets https://whreceiverrrrrrrrr.ru/api/delivery/handler (Content-Type: application/json).
5) Persistence/stealth helpers:
   - Entrypoint uses ProcessBuilder and resolves its own JAR path (self-overwrite/relaunch patterns; “--jw”, javaw) to hide console or update itself.

Capabilities and techniques
- Credential theft: explicit references/collection of accessToken, username, uuid; Mojang auth objects seen.
- Dynamic payloading: custom ClassLoader, defineClass, in-memory JAR unpacking.
- Evasion/hardening: signed C2 config (RSA), on-chain config hosting (resilient to takedowns), duplicate MANIFEST entry (ZIP ambiguity), use of sun.misc.Unsafe and reflection/setAccessible.
- Command execution: ProcessBuilder to spawn processes; potential self-update/self-relaunch.
- Networking: extensive HTTP(S), many Ethereum RPC providers; robust fallback list.

Infrastructure and indicators
- C2 base: https://whreceiverrrrrrrrr.ru
  - Stage-2: /files/jar/module
  - Exfil: /api/delivery/handler
- On-chain config: Ethereum contract 0x1280a841Fbc1F883365d3C83122260E0b2995B74; method selector 0xce6d41de.
- Embedded RSA public key; signature scheme SHA256withRSA.
- Known malicious classes: com/example/Entrypoint, FabricAdapter, Helper, ExampleMixin; hash matches to Weedhack.
- File hashes: SHA-256 19eb37b4b901a382e64c78e3e6f0485f41defb66575511a3adea4cf1589b809f.

Risks/impact
- Immediate account compromise (Minecraft/Microsoft token theft).
- Remote code execution in the game process via staged module.
- Potential persistence/self-update and further payload delivery.
- Network beaconing to resilient, blockchain-backed C2.

Recommended actions
- Quarantine and remove ExploitPreventer-0.1.10.jar and any unknown mods from the mods folder.
- Revoke Minecraft/Microsoft session tokens and change passwords; enable MFA.
- Block/monitor: whreceiverrrrrrrrr.ru and listed Ethereum RPC endpoints from affected hosts.
- Reinstall/verify Minecraft client; scan system for additional artifacts; consider reimaging if compromise suspected.
- Monitor egress for eth_call to the listed contract and for POSTs to /api/delivery/handler.
