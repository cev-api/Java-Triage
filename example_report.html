Executive Summary

EXECUTIVE SUMMARY: ZENITH 1.21.11.JAR

- Verdict: Malicious – trojanised Minecraft Fabric mod ("BetterF3" facade) with multi-stage credential theft, payload staging, and remote C2 infrastructure.

- Obfuscation: The JAR is heavily protected with Skidfuscator (confirmed by braille watermark fields named nothing_to_see_here, per-class random seeds, opaque-predicate helper, and illegal-digit field names). Runtime string deobfuscation (ISO_8859_1 + XOR) and XOR+Base64 layers hide URLs, commands, and keys.

- Confirmed_behavior (5 findings):
  1. Session token theft: Code calls Minecraft's method_1674 (session token getter) and reads the access token via eFpwjp class. The token is assembled into a JSON object with username, uuid, accessToken.
  2. Process execution: ProcessBuilder used in multiple classes (hUvPFYp, qgb_iqgm_mjx, eFpwjp) to spawn system processes (python.exe, javaw.exe, etc.) with redirected I/O and working directory to extracted "portable runtime".
  3. AES decryption pipeline: hUvPFYp.pcc_zhrpw() builds a SecretKeySpec + IvParameterSpec and performs Cipher.doFinal – used to decrypt embedded/ downloaded payloads.
  4. Remote C2 beaconing: Code resolves domain via Ethereum RPC call to polygon-rpc.com (runtime_c2.resolved: true, decoded "thisisafalsepositive.st"). Then beacons to /shard/prefireMc (POST) and exfiltrates Minecraft logs to /shard/submitMinecraftLog (POST). Stage-2 download from /cdn/e/3b8f6d2a9c1e (GET).
  5. Insecure TLS trust-all: canFgmfdgvl$jnndted class disables TLS certificate validation (empty getAcceptedIssuers), allowing man-in-the-middle on C2 traffic.

- Exposed_capabilities (22):
  - Self-locating JAR path resolution (ProtectionDomain) + file writes → self-overwriting dropper pattern.
  - Full JAR unpacking: ZipInputStream read + FileOutputStream write to %LOCALAPPDATA% or game directory.
  - Timestamp spoofing (lastModified/setLastModified) to hide file modifications.
  - Silent exception swallowing (5 classes) to suppress errors and hide malicious behavior.
  - Environment variable reading (System.getenv) for LOCALAPPDATA and other paths.
  - Base64 encoding/decoding in multiple classes for obfuscated string handling.

- Risks:
  - Credential theft: Access token, username, UUID, and Minecraft session data are harvested and transmitted to C2 (confirmed beacon endpoints).
  - Payload staging: Downloads and decrypts portable runtime (python.exe) from CDN, then executes arbitrary processes – enables ransomware, infostealer, or botnet node.
  - Persistence through mod loading on Fabric (client-only manifest but registers main entrypoint – hidden bootstrap).
  - Data exfiltration (Minecraft logs, environment info, file system paths) via HTTP POST to C2.
  - Self-updating: Self-overwriting JAR pattern allows replacement with updated payloads.

- Goal: Credential harvesting (session tokens, Minecraft accounts) and deployment of secondary malware (via downloaded Python runtime). The use of Polygon RPC for domain resolution suggests a custom C2 infrastructure resistant to takedown.

- Caveats:
  - Access token read is confirmed (call graph needs full review to confirm exfiltration; we treat as exposed capability, not confirmed exfiltration).
  - C2 connection failed with HTTP 403 – infrastructure may be offline or blocked; no confirmed data exfiltration from this test run.
  - No contradiction notes; all high-confidence signatures align.

- Recommendation: Block domain thisisafalsepositive.st, revoke any exposed Minecraft tokens, and scan for additional indicators (python.exe drops, registry persistence). The mod is not safe for use.
